# Python Learning & Assignments

This repository contains my Python learning journey, practice work, and assignments completed as part of my development and programming practice.

The repository is organized into separate Git branches to keep practice work and assignment work structured and independent.

## Repository Structure

The repository is divided into three main branches:

### 1. `main`

The `main` branch contains my Python practice and learning work.

It includes:

- Python concept practice
- Programs and exercises written while learning Python
- Experiments with different Python concepts
- Practice projects and implementations
- Other supporting practice work completed during my learning journey

This branch represents my ongoing Python learning and practice.

### 2. `plp-assignment`

The `plp-assignment` branch contains the Python assignments completed as part of the PLP (Python Learning/Programming) coursework.

This branch is dedicated specifically to:

- PLP Python assignments
- Python beginner-level exercises
- Python intermediate-level exercises
- Python advanced-level exercises

The assignment files are kept separate from the general practice work in `main`.

### 3. `datagrokr-assignment`

The `datagrokr-assignment` branch contains the Python assignments completed for DataGrokr.

This branch includes the work related specifically to the DataGrokr assignment, including:

- Python programming tasks
- ETL-related work
- Data processing using Python
- Flask-based work
- SQL/data-related exercises
- Other tasks completed as part of the DataGrokr assignment
